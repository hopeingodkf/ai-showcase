# PersonaStream — Interactive AI Blogger Showcase

Цей проєкт є прототипом інтерактивної вітрини AI-блогерів, розробленим у рамках тестового завдання. Головний фокус: Mobile-First підхід, преміальний UI (Glassmorphism) та створення ефекту "живої присутності" віртуальних персонажів.

## 🛠 Технічний стек
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion (для плавних мікроінтеракцій).
- **AI Art & Assets:** Fooocus / Flux (генерація фотореалістичних облич), LivePortrait (оживлення idle-відео), RVC (клонування голосу).
- **Архітектура:** Pure Frontend (без бекенду), імітація стейт-машини для відео та чату.

## 💡 Унікальні рішення та Інтерактив
Замість статичних карток реалізована ілюзія живого стріму (на прикладі блогера Макса):
1. **Idle-стан:** Безшовне зациклене відео "очікування", що створює ефект живого відеодзвінка.
2. **Імітація діалогу:** Розроблено mock-чат із затримками (typing effect), який імітує реальне спілкування з AI.
3. **Graceful Degradation:** Для інших персонажів реалізована бізнес-заглушка "Офлайн-режим" із CTA-кнопкою переходу в Telegram для утримання трафіку.

За умови виділення серверних потужностей або бюджету на хмарні API, проєкт готовий до інтеграції:
- **Real-Time LLM:** Підключення OpenAI / Anthropic API для генерації відповідей у реальному часі. **Важливо:** логіка API вже повністю написана і відтестована мною на власному потужному локальному сервері (через LM Studio з моделями Qwen 2.5 та Llama-3.1). Застосунок динамічно парсить конфіг моделі, збирає історію чату та генерує відповіді без жодних затримок.
- **Live Video Streaming:** Інтеграція з HeyGen Streaming API або Hedra API для миттєвої генерації lip-sync відео на основі відповідей LLM замість перемикання попередньо згенерованих файлів.
